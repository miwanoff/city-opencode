# AGENTS.md — City Guide

## Стан репозиторію
- у корені лише документація/конфіг: `README.md`, `PRD.md`, `COMPETITORS.md`, `AGENTS.md`, `opencode.jsonc`, `.gitignore`; коду, маніфестів, тестів, лінтерів і CI немає — не вигадуй команди build/test/lint.
- одна гілка `master`, один коміт, без remote; `git push` заборонений конфігом.

## Джерела істини
- `PRD.md` — головний продуктовий документ (статус: початкова концепція, не фінальні вимоги). Читай перед будь-якою реалізацією.
- MVP-сценарій: введення назви міста → пошук і вибір міста (якщо кілька збігів) → отримання місць через зовнішній API → простий список карток із назвою, категорією й доступною короткою інформацією → вибір місця у списку. Окремої детальної сторінки в MVP немає.
- Явно поза MVP: акаунти, власна БД, адмінпанель, карта, фотографії, рейтинги, бронювання. Не додавай це «на виріст».
- Архітектуру та API-контракти PRD не фіксує — уточнюй у міру реалізації.
- `COMPETITORS.md` — лише контекст/дослідження аналогів, не вимоги; ринкові твердження позначені як гіпотези.

## Правила розробки
- PHP без фреймворку, HTML, CSS, JavaScript; нові залежності — лише за погодженням.
- Без бази даних і авторизації на старті.
- Реалізовувати по одній функції, не весь MVP одразу.
- Перед суттєвими змінами коротко пояснити план.
- API-ключі та інші секрети не записувати в код і Git.
- Після змін виконати доступні перевірки й повідомити результат.
- `PRD.md` не змінювати без погодження.

## Обмеження OpenCode (`opencode.jsonc`)
- заборонено читати `*.env` і `*.env.*`; `*.env.example` дозволено;
- довільні shell-команди й доступ поза каталогом проєкту вимагають підтвердження;
- дозволені без підтвердження: `git status *`, `git diff *`, `git log *`; `git push *` — заборонений.

## Невирішене в PRD (перевіряй перед реалізацією)
- API остаточно не обрано: OpenTripMap (безплатний тариф **non-commercial**, не для комерційного запуску), Geoapify Places для місць, GeoNames для пошуку міст. Перевіряй покриття міст, наявність кафе/парків/музеїв, українську мову, ліцензію, атрибуцію, ліміти й вартість; не припускай, що один API покриває все.
- Не зафіксовано: країни/міста для першого тесту (перевірити на 3–5 містах), межі міста, мову інтерфейсу, чи достатньо перегляду місця у списку.
- Документація ведеться українською; мову UI-текстів узгоджуй окремо, бо в PRD це відкрите питання.
