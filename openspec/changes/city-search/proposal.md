# Proposal

## Why

Користувачам потрібен простий спосіб швидко знайти потрібне місто за назвою, щоб перейти до перегляду цікавих місць у наступному кроці MVP. Перша функція City Guide має дати зрозумілий сценарій пошуку та вибору міста без акаунтів, власної бази даних і зайвих залежностей.

## What Changes

- Додати першу функцію MVP: пошук міста за назвою через Geoapify та вибір потрібного збігу користувачем.
- Показати головний екран із назвою продукту, полем введення міста та кнопкою пошуку.
- Відображати список валідних збігів лише для населених пунктів міського рівня (`city/town` за класифікацією Geoapify; точне мапування полів підтверджується під час реалізації).
- Для кожного збігу показувати назву міста та країну/регіон, якщо ці дані доступні.
- Вимагати явний вибір користувача кліком навіть тоді, коли знайдено лише один валідний збіг.
- Після вибору зберігати в стані поточного екрана мінімальні дані міста: `place_id`, назву для відображення, країну/регіон (якщо є), `lat/lon` (якщо є).
- Обробляти стани завантаження, «місто не знайдено», помилку запиту/недоступності сервісу та можливість повторити пошук.
- Обмежити реалізацію безкоштовними можливостями Geoapify на поточному етапі; не додавати карти, зображення, nearby-пошук, БД та адмінпанель.

## Capabilities

### New Capabilities

- `city-search`: Пошук міста за назвою, показ валідних збігів, явний вибір міста користувачем і збереження мінімальних даних обраного міста для наступних кроків MVP.

### Modified Capabilities

- Немає. Існуючих specs у проєкті немає, а поведінка на рівні вимог ще не зафіксована.

## Impact

- **Затронуті частини:** майбутній frontend/UI головного екрана, клієнтська або серверна інтеграція з Geoapify, обробка станів запиту, локальний стан вибраного міста в межах екрана/браузера.
- **Зовнішні залежності:** Geoapify API для пошуку міст за назвою; використання лише безкоштовних можливостей на поточному етапі. API-ключ не зберігається в коді або Git.
- **Обмеження:** PHP без фреймворку, HTML/CSS/JS; без БД та авторизації; одна функція за раз. Карти можуть бути підключені пізніше через інший API; nearby не потрібен; зображення та інші розширення — пізніше.
- **Ризики/перевірки:** підтвердити точний Geoapify endpoint/параметри для пошуку міст, мапування полів (`place_id`, назва, країна/регіон, `lat/lon`), фільтрацію `city/town`, ліцензію/атрибуцію/ліміти та якість результатів на 3–5 тестових містах різних країн/скриптів.
