# City Guide

Навчальний вебзастосунок: користувач вводить назву міста, обирає знайдений населений пункт і бачить список цікавих місць із зовнішнього джерела даних. Перший реліз — без акаунтів і власної бази даних.

## Технології

PHP без фреймворку, HTML, CSS, JavaScript. Нові залежності додаємо лише за погодженням.

## Поточний стан

Репозиторій містить лише документацію: `PRD.md`, `COMPETITORS.md`, `AGENTS.md`, `opencode.jsonc`, цей `README.md` і `.gitignore`. Коду, точок входу, API-інтеграції й тестів ще немає.

Вимоги та межі MVP — у `PRD.md`, правила роботи в репозиторії — в `AGENTS.md`.

## Запуск

Спосіб запуску ще не налаштовано: виконуваних файлів і скриптів поки немає. Розділ буде доповнено, коли з'явиться перша сторінка.
